# Community Lore Enrichment

This layer adds **deep community lore** to the NRCU vault characters, mined from the
Nous Research Discord archive (Talio). The vault's existing cards are visual-first;
this section adds the real voices, backstories, and friction that make characters
**not flat** — the want/need, the sacrifice, the relationships.

## Principle
- The **community IS the cast**. Anyone who participates is welcome.
- No pedestals, no inner-circle-only. Everyone has a want and a friction.
- Real quotes beat invented backstory — the archive gives us the actual words.

## Format
Each character file in `characters/` gains a `## Community Lore` section + a
`## Friction / stakes` section (story-engine framing). Existing visual canon is untouched.
